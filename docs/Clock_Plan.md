# 时钟、复位与时序约束

PL 参考：N18 / 50MHz / 20ns。ADC MMCM 的 VCO 为 650MHz（50×13），提供 100MHz 系统时钟，以及 10/25/50/65MHz 分支。100MHz 使用输出0的 6.5 分频；ADC 分支分别分频65/26/13/10。BUFGMUX 选择只允许在 STOP、握手完成后改变，硬件分支存在不等于已经实测开放。

视频级联 MMCM：以100MHz为输入，100×37.125/5=742.5MHz VCO，/10=74.25MHz、/2=371.25MHz。视频参数为1650×750总周期、1280×720有效区、110/40/220水平消隐和5/5/20垂直消隐。OSERDES为10:1 DDR，数据位速742.5Mb/s。精确频率使用级联结构，未以近似频率冒充74.25MHz。

## 复位

MMCM锁定参与复位请求，各域由同步链释放。系统100MHz来自PL，视频和诊断不等待DDR。proc_sys_reset 的外部端口必须声明 ACTIVE_HIGH，C_EXT_RESET_HIGH 的生成值必须为1；构建脚本核查该值，不把只读参数设置告警当成设置成功。视频失锁时同时复位显示握手的两端。

## ADC 外部时序

ODDR外送时钟，输入 IOB 寄存器在下一上升沿接收上一采样输出。ADI AD9226 Rev.B p3规定tOD为3.5–7ns、流水线延迟7周期。XDC以外送端口的生成时钟作为输入延迟参考，暂加0–3ns外部连线/负载往返余量，因此min=3.5ns、max=10ns。该余量是工程假设，必须用实际模块/跳线和探头闭环，不能据此宣称65MSa/s已验收。

四种互斥生成时钟都有名称和master_clock；只将同一物理MUX上不能同时存在的速率声明physically_exclusive。不存在CLOCK_DEDICATED_ROUTE=FALSE或ADC输入整片false_path。

## CDC 证明

- 配置、统计、ROLL元数据和状态：单请求/应答邮箱。数据与REQ同边沿写入，至少经过目的域两级REQ同步后才捕获；源保持到ACK返回。因此目的域至少两个周期稳定窗口，最快目的域100MHz。hold_data→ddata物理路径以10ns datapath-only上限约束；仅REQ/ACK第一级触发器排除异步时序检查，第二级保持正常时序。
- 显示：后缓冲写完后REQ；像素域仅在垂直消隐边界切bank并回ACK。CPU/PL在pending时禁止再写。metadata同样保持到ACK，以10ns约束。
- BRAM记录：ADC冻结且最后写入完成后，经状态邮箱通知系统域；CPU完整复制后才释放。
- DMA：XPM异步FIFO，AXIS背压不会反向暂停ADC。满时停止当前DMA源并明确累计未交付点数；后续传输前可独立复位FIFO。
- 异步按键：只排除到第一级同步触发器的路径；消抖、持续时间及组合键判定在系统域。

数字采样序号标记的是FPGA接收的数据拍；外部模拟信号相位还包含ADC七拍流水线及FPGA输入寄存延迟。未校准模拟群延迟时不把它当探头端绝对时间。

TMDS四路是源同步串行输出，外部接收器眼图/线缆裕量仍须实板确认；不得通过捏造显示器setup/hold值来清除HDMI串行输出的静态分析提示。

## 本次交付的速率门控

交付RTL设置ENABLE_RATE_SWITCH=0，rate_sel在硬件中固定为00；25/50/65写请求返回SLVERR。当前XDC只描述真实可达的10MHz路径，没有用case_analysis隐藏仍可访问的模式。所有速率探索报告另存all_rates_exploration；65MHz输入路径在暂定外部延迟下为负裕量，因此未发布高速资格。

DMA复位请求先在100MHz域寄存，再送8级异步置位/同步释放链，消除了reset/flush组合逻辑进入同步器的CDC-10。显示metadata寄存器禁止重定时，保证其握手物理边界与max_delay端点一致。

640×480降级使用25.2MHz像素/126MHz串化时钟，800×525总周期形成60Hz；逻辑1280×720布局映射至实际分辨率，字形压缩采用相邻位/行合并，波形用相邻两列Min/Max合并，避免缩小画面漏掉窄峰。自动降级在构建时发生，不宣称已实现EDID或显示器兼容性的在线判断。

## 静态分析提示的处理

CDC-15/17是有请求/应答及保持条件的数据邮箱，已用固定种子跨域测试和10ns数据路径上限验证；保留原始提示及协议证明，不把多位数据逐位打拍。CDC-10组合复位输入已改成单一寄存请求，最终构建对CDC Critical设硬门禁。HDMI四个串行P端口的no_output_delay提示保留，因为外部TMDS眼图不能用一个虚构的并行采样setup值代替；内部像素/串化、所有ADC输入及内部端点均受约束。
