# 2026-10-17 四档采样 / 真实来源 / 实板验证版

本版替代仅 10MSa/s 的 boardfix 候选版。当前正式 bit 的内嵌 RTL 版本为 a2c9e43f，ARM 固件为 7eea22be；交付脚本及文档提交见 Release_Manifest.json。

- 修正测试后遗留 SIM 的默认行为：上电 REAL ADC，显式 SIM 有持续告警，切来源清除旧结果。
- 频率测量增加幅度、周期数、周期离散度及 OTR 有效性检查；浮空噪声和单脉冲不会显示固定频率。
- 开放 10/25/50/65MSa/s；无毛刺切换、高速接收相位、上一转换值的时序关系均有回归和逐档 STA 门禁。
- SYS 域独立 DDR 压力源验证约 199.94MB/s；四档完整 1Mi 点 DDS 序列比对通过，当前档位自检后开放 MEM/SEG。
- 添加实际 RGB 像素 CRC32、三域 ILA、八段 CRC/时间戳诊断、精确 CDC 审查及未知路径拒绝测试。
- 修正 EYE 长时间 64bit 样本序号折叠溢出、配置读回未同步真实时钟、测试采集遗留旧来源等问题。
- 一键下载会核对发布文件、验证 ARM 心跳、自动自检并恢复真实 MEM 记录。五次热重启和独立新目录重建均通过。

实际 HDMI、15 组 RTL、C/NumPy、1000 次切换、ILA 与长测证据见 Acceptance.json 及 results/2026-10-17/prd_completion。电压比例、外部已知信号、板级时延及本轮未连接的 UART 不会被写成已完成的仪器验收。P2 高级触发/CDR/BER 保持未实现；DPX/EYE 使用允许的 160×90 降级，MEM 为有限 1Mi 点记录。
