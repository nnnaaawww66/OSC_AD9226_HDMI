# ADC/DAC 4.0 扩展说明

本说明补充原 PRD 的 ADC 工程。用户在 2026-10-17 明确要求加入 DAC904、中文高清文字与坐标、串口上位机、工程备份和 Flash 固化。Flash 写入采用这次明确授权；旧 PRD/文档中的“不写 Flash”不再适用于最终交付流程。

## 已知模块参数与电压

用户提供 AD9226 **模块输入量程 ±5V @50Ω**、DAC904 **模块标称输出 5Vpp**。这些是模块连接器参数，不能用 AD9226 芯片的 1/2Vpp 跨度替代。ADC 初始换算为 10V/4095 code、零码 2047.5，并明确标为标称；`cal` 只应用实际测得的增益/零点。数字增益和中心电平改变后坐标刻度使用同一映射反算。

5Vpp 的零中心波形为 ±2.5V；直流偏置、50Ω/高阻负载和模块前端实际传递函数仍需核实。DAC 幅度和偏置必须共同落在 0～16383 code，软件不自动把 ADC 当前校准或模式用于 DAC。DAC 预览表示配置的数字波形表，不冒充模拟回读。

DAC904 数字输入使用直二进制，上升沿锁存。TI SBAS095C p5 给出建立时间至少 1ns、保持至少 1.5ns，时钟高低电平各至少 3ns。本设计独立固定 50MHz，下降沿更新 14 路 IOB 输出，上升沿由芯片锁存。XDC 额外计入数据相对时钟 ±1ns 的暂定外部走线偏差；必须区分这些工程预算与已测得的板外时序。

DAC904 数字电源为 5V 时 VIH 最小 3.5V；3V 条件下为 2V。当前 FPGA 输出为 LVCMOS33，DAC 模块是否含 3.3V 数字电源或电平转换，不能由“5Vpp 输出”推断。接口模拟输出性能与数字电源适配以实际模块电路为准。参考：[TI 官方数据手册](https://www.ti.com/lit/ds/symlink/dac904.pdf)。

## 独立性

DAC 使用独立 BUFG 分配板卡 50MHz 基准；ADC 的采样率选择、触发、RUN/STOP、SIM/REAL、FFT、回放均不进入 DAC 信号通路。DAC 有单独的双缓冲 2048×14-bit 波形表、32 位 DDS、配置握手和状态快照。ADC 与 DAC 仅共用整板电源/启动、板卡基准、PS、串口和显示资源。全板复位/重新下载会重启双方。

`page adc` / `page dac` 只切换 PS 渲染页面，不停止后台采集或 DAC 更新。DAC `enable 0` 是输出中点码 8192，并非掉电/高阻；PD 未在给定接线中。

## 引脚与寄存器

DAC 时钟 D20；数据 D0..D13 依次为 G18、G17、B20、C20、J16、K16、H18、J18、G20、G19、H17、H16、D18、E17，均为 Bank35 LVCMOS33。地线按用户给定已连接开发板真实 GND。

寄存器沿用基址 0x40000000，扩展偏移如下：

- 0x100：待提交 DDS phase step。
- 0x104：bit14 运行、bits13:0 停止保持码。
- 0x108：写 bit0 提交；读 bit0 busy、bit1 提交的 bank。
- 0x10C：读 DAC 时钟计数，并锁存同一时刻的完整 DAC 状态。
- 0x110：固定更新率 50000000。
- 0x114：锁存的 DDS 相位。
- 0x118：锁存的 bits15:2 数字输出码、bit1 运行、bit0 bank。
- 0x30000～0x31FFC：2048 点待提交表，32 位对齐、低14位有效，支持实际存储读回。
- 0x80000～0x8257C：80×30 字符界面，低9位为字形索引。
- R_OWNER bit8：DAC 页面。该位不写入 ADC 工作模式寄存器。

## 显示与串口

HDMI 使用原生 16×24 字符单元和中文点阵 ROM，不再把 8×16 ASCII 字体简单放大。波形纵轴按当前增益/中心/标称或校准系数显示，横轴随采样率和视窗变化；FFT 为 Hz/dBFS，EYE 为 UI/电平，DPX 有时间/电平及命中强度，ROLL 为相对当前的时间，MEM 为记录起点时间，SEG 为相对触发时间，DAC 为双周期时间/%FS。FFT 横轴使用降采样后的有效采样率。

串口 COM27，115200 8N1。兼容原 ASCII 命令，增加 `settings`、`page`、`view`、`autoscale`、`rearm`、`uart` 和 `dac` 命令。上位机以 `@12345678 command` 发请求，回复含相同 `rid=12345678`；中断接收到 1024 字节环形缓冲。长表分块不超过24点，每块确认，连续长度2048点、CRC32和实际 FPGA 读回通过后才提交。CRC 计算对象为2048个小端 uint16码值。

常用示例：

```
page dac
dac set sine 1000 0.1 0.5 0.5 0
dac enable 1
dac status
dac enable 0
page adc
view span 1024
view gain 2
view zero 2047.5
view auto 1
settings
```

`dac set` 参数为波形名、Hz、峰峰值/FS、偏置/FS、占空比、运行0/1。`sine/square/triangle/saw/dc` 在 PS 生成表；任意表达式与 CSV 在上位机经白名单/范围检查后上传。0.1Hz～5MHz 是数字设定范围，实际 DDS 分辨率约0.01164Hz；高频每周期采样点减少，不代表已完成模块模拟带宽/SFDR 校准。

上位机使用说明见 [host/README.md](../host/README.md)。最终启动镜像包含实际 HDF 对应的 FSBL、通过时序检查的 bit 和应用 ELF。QSPI 备份、写入、校验及冷启动结果以本次交付报告和日志为准，不能复用旧 ADC 版本的长测结果冒充新版本验证。
