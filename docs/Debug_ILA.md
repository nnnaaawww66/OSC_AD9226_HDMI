# ILA 与数字链路调试

使用本机 Vivado 2018.3 Catalog 的 ILA v6.2，3个独立时钟域、各1024深度，不占用UART。构建同时输出 scope_top.ltx。正常源默认为真实 ADC；SIM 需显式选择。capture_ila.tcl 只读调试核心并运行易失DDR压力测试，不写Flash。

ADC 128位：127:104 DDS相位；103:72 样本计数低32位；71:58 触发地址；57:44 记录起点；43:30 写地址；29:27 触发状态；26写使能；25 ready；24 OTR；23:12 IOB原始ADC；11:0 编码转换后的实际采集值。

SYS 128位：127:112 AXIS DATA；111 VALID；110 READY；109 LAST；108:96 FIFO水位；95:83 FIFO高水位；82 ADC DMA active的邮箱快照；81:66 已生产点数低16位邮箱快照；65直方图忙；64栅格忙；63:57 hit FIFO高水位；56:43 hit地址；42 hit；41:28栅格地址；27栅格valid；26:19错误锁存低8位；18配置忙；17释放忙；16显示提交忙；15:0 AXIS已接收计数低16位。

VIDEO 64位：63:56视频帧计数低8位；55:53已提交模式；52:29 RGB888；28:17原始x；16:5原始y；4 HS；3 VS；2 DE；1视频MMCM锁定；0显示前bank。RGB/DE已经过流水线；x/y为时序发生器原始坐标，分析时需计入显示流水线延迟。

实际RGB像素CRC：0x400000F8，只统计DE有效的R/G/B字节，反射IEEE CRC32，多项式0xEDB88320，初值和最终异或均0xFFFFFFFF；每帧垂直消隐时锁存。独立Python zlib已用于校验RTL导出的完整帧。0x70仍是软件文字/包络/密度资产CRC，二者含义不同。
