# Z7 LAB 上位机

Windows 发布版：解压整个 `Z7_LAB` 目录，运行 `Z7_LAB.exe`，保留旁边的 `_internal` 目录。串口选择 **COM27**，115200、8N1。请先烧写配套 4.0 固件；本程序使用带请求编号的 RPC，不会把其他命令的迟到回复当作成功。

源码运行：Python 3.10+，安装 `requirements.txt`，再运行 `launch.ps1` 或 `python app.py`。主界面分为 ADC、DAC 和系统诊断；控件修改后按对应的“应用”按钮才发送。后台轮询不覆盖正在编辑的控件，“读取板卡参数到控件”可同步板卡当前配置。

重新生成 Windows 发布版：在安装了上述依赖和 PyInstaller 的 Python 环境执行 `host/build_exe.ps1 -Python <python.exe路径>`。输出在 `host/dist/Z7_LAB`，需复制整个目录。该打包流程不连接板卡。

ADC 支持七模式、四档采样率、RUN/STOP、自动缩放、连续自动缩放、时间视窗、垂直增益、中心电平、触发方式/边沿/电平/滞回、FFT 点数/窗函数、EYE 码率、长存储起点与分段选择、DDR 自检和采集、实测校准、HDMI 菜单操作、状态和日志。长存储/分段模式先执行自检。

DAC 独立使用固定 50MSa/s 时钟和 2048 点双缓冲波形表。支持正弦、方波、三角波、锯齿、直流、数学表达式和 CSV；频率 0.1Hz～5MHz。频率由 32 位 DDS 量化，预览显示实际可设定频率。高频时每周期样本减少，不能将理想表形状当作模拟带宽/占空比精度的保证。

数学表达式使用 `t∈[0,1)`、`pi`、`e` 和界面列出的数学函数；结果必须在 -1～+1。例如 `sin(2*pi*t)`、`where(t<0.25,1,-1)`、`0.8*sin(2*pi*t)+0.2*sin(6*pi*t)`。使用 AST 白名单解释器，禁用属性访问、下标、导入和 Python eval。CSV 输入为单列 -1～+1 样本，周期插值到 2048 点。导出的数字表 CSV 记录 0～16383 码值；它与归一化输入 CSV 的单位不同。

上传包含连续块编号、完整长度、CRC32、FPGA 实际表存储读回及提交确认。提交前旧波形连续输出，提交后才切换。预览上的“已确认”表示数字表已通过确认，**不表示测量过 DAC 模拟输出**。当前仅最后确认表保存在本机内存；配置可保存为 JSON，重载默认不勾选输出开启。

用户给定 ADC 模块量程 ±5V @50Ω、DAC 模块满量程 5Vpp。ADC 默认以 10V/4095 code、零点 2047.5 作标称换算，HDMI 标明“标称值”，不冒充实测校准。DAC 幅度使用 %FS，5Vpp 换算仅为标称估计；实际直流偏置、负载与模块增益需实测。幅度与偏置共同检查，任何样本都必须在 14 位码值范围内。软件停止 DAC 保持中点码 8192；PD 未接入，因此不是高阻或物理掉电。

ADC 与 DAC 不共享采样数据、触发、波形表、频率参数或运行状态；PS 页面切换仅改变显示。两者使用同一块板上的电源、50MHz 基准、系统启动及串口管理接口。

自定义表达式/CSV 的满幅峰峰值定义为归一化 -1～+1 的跨度；未达到 ±1 的表达式不会自动放大。预览根据实际数字表最小/最大值计算峰峰值及标称 Vpp。零值偏置是表达式 y=0 对应的位置，与自定义表自身的直流分量分别考虑。
